🌸 1. Server Installation (Guided by Sabrina)
🌸
Sabrina: "Hey there! I'm Sabrina. Setting up your self-hosted Haven Server is super easy. Follow these 3 simple steps to get our bare-metal C# backend running on your PC or server!"
1

Clone the Server Repository

Ensure you have .NET 10 SDK installed on Windows or Linux, then run:

git clone https://github.com/Haven-AI-Companion/haven-server.git cd haven-server
2

Build & Launch

Compile the server with bare-metal Release optimizations:

dotnet run --configuration Release
3

Verify Health Check

Open http://localhost:18799/health in your browser. You should see status: ok!

⚔️ 2. Hardware Requirements & Speed (Guided by Kaelen)
⚔️
Kaelen: "Greetings! I'm Kaelen. Haven Server features an automatic hardware profiler that detects your CPU cores and RAM to pick the optimal thread count for bare-metal speed!"

💻 Minimum CPU Requirements

6 CPU Cores, 16 GB System RAM. Generates 15–25 tokens/second using standard CPU threads!

🚀 GPU Acceleration (CUDA / Metal)

Automatically offloads model layers to NVIDIA CUDA GPUs or Apple Silicon Metal for sub-3-second responses.
