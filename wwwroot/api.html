🔑 Authentication
POST /api/auth/login
Authenticates user and returns a Bearer JWT Token.
Request Payload
{ "username": "daniel", "password": "your_password" }
GET /api/auth/me
Retrieves the active authenticated user profile.
Header
Authorization: Bearer <JWT_TOKEN>
👥 Companions & Cards
GET /api/companions
Lists all available companions on the server.
GET /api/companions/{name}
Gets full configuration JSON for a specific companion.
POST /api/companions
Saves or updates companion configuration card JSON.
Request Payload
{ "name": "Sabrina", "description": "...", "personality": "...", "clothingState": "fully clothed" }
POST /api/companions/{name}/avatar
Uploads a high-res avatar image for a companion (multipart/form-data).
POST /api/companions/import-card
Imports a Tavern V2 / V3 PNG Character Card with embedded haven_metadata.
💬 Conversations & Real-Time State
GET /api/conversations
Lists all conversation sessions for the authenticated user.
GET /api/conversations/{id}/messages
Gets history messages for a specific conversation.
GET /api/conversations/{id}/state
Fetches active real-time companion state (location, outfit, mood, clothing state).
POST /api/conversations/{id}/state
Updates companion real-time state parameters from the app.
Request Payload
{ "location": "beach", "outfit": "swimsuit", "mood": "playful", "clothing_state": "naked" }
🧙‍♂️ AI Card Studio Wizard
POST /api/companions/generate-profile
Drafts a structured character JSON card from a text prompt via LLM.
Request Payload
{ "prompt": "An elven paladin companion named Lyra" }
POST /api/companions/generate
Generates a complete character card profile AND illustrates a custom Stable Diffusion avatar image.
⚡ WebSocket Real-Time Chat Engine
WS /ws/chat?conversation_id={id}&companion_name={name}
Full-duplex WebSocket connection for token streaming, live keep-alives, and instant selfie markdown rendering.
Outbound Message Payload
{ "content": "Hey Sabrina, send me a selfie!", "model_id": "haven-chat-v3.0.3" }
Inbound Token Stream
{ "type": "token", "content": "Here is a selfie!" } { "type": "token", "content": "\n\n![Selfie](/uploads/companion_sabrina_123.png)" } { "type": "done" }
🛡️ Admin & System Health
GET /health
Returns system health, database status, CPU/RAM profiling, and active sidecars.
POST /api/admin/backends/select-primary
Hot-toggles primary AI backend between Ollama API and Native C++ sidecar.
